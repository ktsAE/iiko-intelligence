# iiko Intelligence для Windows

## Первый запуск

Это локальная сборка 0.4.1. Используйте переданный вам ZIP этой версии. На GitHub доступна предыдущая сборка 0.3.1 с восемью инструментами.

1. На компьютере с 64-разрядной Windows распакуйте весь архив в постоянную папку, например в «Документы». Дважды нажмите `Setup-iiko.cmd`. Python и библиотеки входят в архив. Для установки интернет не нужен.
2. Дождитесь надписи **Setup verified**. Теперь можно попробовать любой из двух вариантов ниже. При первом запуске используются учебные данные за июль–сентябрь 2026 года.

## Обновления

После первой установки этой версии введите в локальном Codex **«Обнови iiko»** для немедленной проверки. При обычной работе коннектор сам проверяет стабильные релизы на GitHub в фоне раз в сутки. Если есть новая версия, он скачает её, сверит SHA-256 и проверит подключение MCP. В ответе на рабочий вопрос появится уведомление. Заново откройте проект в локальном Codex, чтобы воспользоваться обновлением. Отчёты, настройки и подключение к iiko сохраняются в прежней папке. Без интернета остаётся доступна установленная версия и локальные отчёты.

В версиях 0.3.1 и 0.4.0 этой функции ещё нет. Для разового перехода закройте сеанс с коннектором. В локальном Codex откройте родительскую папку и попросите: «Обнови существующую папку iiko Intelligence до сборки с автообновлением. Сохрани данные и настройки и проверь MCP». После публикации Codex может взять сборку из официального релиза; до публикации нужен переданный локальный архив 0.4.1.

## Обычный чат ChatGPT

Дважды нажмите `Report-for-ChatGPT.cmd`. Откроется папка `reports` с текстовым отчетом. Просмотрите его и, если эти данные можно передать в ChatGPT, прикрепите файл к обычному чату. Ничего подключать в настройках ChatGPT для этого не требуется. Каждый файл отражает данные на момент его создания.

Пример вопроса — «В какие дни выручка была выше всего? Укажи даты и суммы. Какие блюда лидируют по выручке?»

## Прямое подключение MCP

В приложении ChatGPT для Windows выберите **Codex → Local**, откройте распакованную папку `iiko-intelligence` и подтвердите доверие к ней. Введите `/mcp` и найдите `iiko_intelligence`. Спросите «Какие данные доступны и за какие даты? Сравни первую и вторую недели сентября и покажи, какие блюда дали наибольшую разницу».

## Техкарты, себестоимость и складские документы напрямую из iiko

1. Получите у администратора UUID организации, appId, clientSecret и apiKey для российского iiko Cloud. Ключ должен видеть одну организацию и иметь права на нужные отчеты. Обычный логин iikoOffice для этого подключения не подходит.
2. Дважды нажмите `Connect-iiko-Cloud.cmd` в распакованной папке. Введите данные в открывшемся окне. После проверки организации программа сохранит профиль в зашифрованном виде для текущего пользователя Windows.
3. В локальном Codex спросите «Найди салат “Цезарь”, покажи действующую техкарту на 20 ноября 2026 года и себестоимость ингредиентов по складу “Кухня”». Для проверки откройте одну знакомую техкарту за ту же дату в iikoOffice. Для стоимости укажите дату, время и часовой пояс ресторана.
4. Для склада и документов попробуйте «Какие были остатки на конец дня?», «Что насчитали при последней инвентаризации?» или «Покажи позиции и цены приходной накладной № 0128 за эту неделю». Выберите склад и подтвердите блюдо, если есть несколько совпадений. В ответе проверьте дату и статус документа.

`Disconnect-iiko-Cloud.cmd` удаляет локально сохраненный профиль. Можно продолжать работать с загруженными отчетами. Полный перечень методов приведен в `IIKO_DATA.md`.

## Загрузка своих продаж

1. В iikoOffice откройте **OLAP-отчет по продажам**. Выберите один ресторан и закрытый период. Добавьте **Учетный день**, **Код блюда**, **Блюдо**, **Количество блюд** и **Сумма со скидкой**. Сохраните одну строку на блюдо за день. Если дата указана один раз на группу, сохраните числовой итог за каждый такой день.
2. Выгрузите отчет в Excel (`.xlsx` или `.xls`) или CSV. Запишите общую сумму со скидкой, которую показывает iikoOffice с этими же фильтрами. Храните исходную выгрузку вне папки программы.
3. Перетащите файл на `Import-iiko-report.cmd` или откройте эту команду и введите путь к файлу. Укажите даты, сумму из iikoOffice, название ресторана и валюту. Каждый раз используйте для заведения одно и то же уникальное название.
4. Дождитесь **Report ready**. Спросите в Codex «Покажи пять самых продаваемых блюд по количеству» или создайте новый файл для обычного чата. Новый импорт полностью заменяет предыдущий период продаж. Для сравнения двух недель включите обе в одну выгрузку.

## Остатки на складе

После загрузки продаж откройте в iikoOffice **Остатки на складах**. Выберите один склад и дату. Сохраните плоский отчет с одной строкой на товар и колонками **Артикул**, **Наименование**, **Ед. изм.**, **Количество**, **Себестоимость**. Для последней колонки нужна стоимость всего остатка по строке. Сверьте итоговую стоимость по всем строкам с итогом iikoOffice.

Перетащите выгрузку на `Import-iiko-stock.cmd`. Введите то же название ресторана и валюту, затем склад, дату и общую стоимость. При успешной сверке появится **Warehouse snapshot ready**. В Codex можно спросить «Какие позиции имеют отрицательный остаток? Назови склад, дату, товар и количество». Каждая загрузка остатков заменяет предыдущий складской отчет. Дата склада может отличаться от дат продаж.

## Закупки и списания

1. В iikoOffice выберите один ресторан и закрытый период. Для закупок возьмите проведенные приходные накладные от поставщиков. Для списаний возьмите проведенные складские акты списания. Исключите удаленные документы, черновики, перемещения и возвраты. Запишите количество документов и общую сумму именно этого списка.
2. В папке `examples` откройте `purchases-template.csv` для закупок или `writeoffs-template.csv` для списаний. Сохраните свою копию вне папки программы. Заполните одну строку на документ. Укажите дату, номер, тип (`incoming_invoice` или `writeoff_act`), статус `posted`, поставщика или склад и сумму всего документа. Если статус показан в iikoOffice цветом, сначала проверьте его там. Номера с начальными нулями сохраняйте как текст.
3. Перетащите файл на `Import-iiko-documents.cmd`. Выберите вид документа, введите количество, период и итоговую сумму из iikoOffice. Дождитесь **Document list ready**. Каждый вид документов хранит свой последний сверенный период.
4. В Codex спросите «У каких поставщиков самая большая сумма приходных накладных за этот период?» или «Покажи сумму актов списания по складам». В текстовый отчет попадают суммы и количество документов с датами каждого списка.

## Если ресторан использует iiko Cloud

Для ежедневной работы достаточно выгрузок. Если администратор выдал отдельный ключ к отчетам российского iiko Cloud и подтвердил доступ к одному заведению, запустите `Sync-iiko-Cloud.cmd`. Понадобятся UUID организации, точное название заведения в OLAP, даты и контрольная сумма. Приложение запросит секреты в терминале. Доступ конкретного ресторана проверяется при подключении.

## Если что-то не получилось

- **Не сходится сумма.** Проверьте заведение, даты, скидки, возвраты и общую сумму в iikoOffice. Для склада проверьте дату остатков и полную стоимость по строкам. Предыдущий отчет сохраняется при ошибке.
- **Несколько листов.** Введите название нужного листа из предложенного списка.
- **В ответе учебные данные.** Проверьте, появилась ли надпись **Report ready** при импорте продаж и открыта ли именно эта папка в Codex.
- **Перенесли программу или переходите со старой версии вручную.** Закройте окно локального проекта. Сохраните копию папки `data`, затем распакуйте новую версию поверх той же папки и повторите `Setup-iiko.cmd`. Установка проверяет подключение и обновляет созданные ею пути.
- **В браузере нет настройки MCP.** Для обычного чата используйте текстовый отчет. Прямое браузерное подключение через защищенный туннель описано в README.
